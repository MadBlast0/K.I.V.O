# K.I.V.O.

**Knowledge • Intelligence • Voice • Operations**

KIVO is a Windows-first, voice-first AI desktop companion: the intelligent voice and
operations layer between you and your Windows computer. Local wake word and speech,
interchangeable AI backends (cloud, CLI agents, local models), and native computer
control, with explicit permissions throughout.

> Status: early planning (Phase 0). See the [project blueprint](docs/KIVO_Project_Plan.md).
